A scoretracker-worker is a process that should be executed manually by the user, on a machine that they have access to.

A worker process can send API requests to the server on behalf of the client, using a Worker API key, generated by the user via the scoretracker frontend.
For example, a worker may post new performances and matches.

A worker process can send API requests to library services and fetch their resources. Or, if the worker lives on the same machine as a library, it can use the local files directly for faster access. It can also send new files to libraries, and also set metadata for the files on the server. Accessing external libraries may require additional authentication keys provided by the user manually.
For example, a worker may "fold" a video and save it back to a library (same or different), and save the fact that it is a folded video to the server.
